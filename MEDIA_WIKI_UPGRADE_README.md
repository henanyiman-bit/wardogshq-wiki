# WARDOGS Wiki Media + Database Upgrade

This patch addresses the local-review finding that the site looked like a text guide with a Wiki shell rather than a media-rich game Wiki.

## Changed
- Public sidebar no longer exposes internal SEO labels such as Search Intent / Page Type.
- Added visible source attribution for official images.
- Added media figures inside article flow instead of only at the hero.
- Expanded Map into a systems reference with a map-mechanics flow and role table.
- Expanded Weapons into verified entity cards for Deagle, PP-19 drum, 7.62x54mm AP and 5.56mm AP.
- Expanded Vehicles into verified entity cards for 10 named official vehicles.
- Added contextual official media to Loadouts, FOB and Control Zone pages.
- Added official reveal video inside the Guide Hub article flow.

## Evidence boundary
The patch does not invent missing weapon stats, vehicle armor/speed, map coordinates, or fake entity images. Contextual official screenshots are explicitly captioned as contextual media when the official source does not identify the exact entity shown.
