# WARDOGS Final Richness Expansion

This patch expands the site from overview-style pages into a database-style Wiki.

## Added
- 35 individual weapon entity pages
- 20 individual vehicle entity pages
- 3 individual map pages
- full linked weapon and vehicle tables
- additional map, loadout, money and faction media
- visible source boundaries for official vs secondary current-build data
- wider desktop Wiki layout and denser database navigation

## Data policy
Official Team17/Steam sources remain authoritative for core systems. GameWatcher is used for current observed weapon/vehicle stat tables because the official sources do not expose complete per-entity live stat databases. These secondary values are explicitly labeled as version-sensitive.
