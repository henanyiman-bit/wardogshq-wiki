## Patch 0.11: server-browser changes

Patch 0.11 was explicitly positioned as a server-browser improvement update. The practical Wiki effects include clearer Community/Official browsing, improved community discovery, text search and persistent server identity. These changes belong on the [Community Servers](/community-servers/) page as well as in the version archive.
