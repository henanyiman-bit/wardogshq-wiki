## Official PC requirements

<div class="table-wrap">

| | Minimum | Recommended |
|---|---|---|
| OS | Windows 10 | Windows 11 |
| CPU | Intel Core i5-8600 / AMD Ryzen 5 3500 | Intel Core i7-12700K / AMD Ryzen 7 5700X |
| Memory | 16 GB RAM | 16 GB RAM |
| GPU | Nvidia GTX 1660 / Radeon RX 590 | Nvidia RTX 3070 / Radeon RX 6700 XT |
| Storage | 50 GB available | 50 GB available |
| Network | Broadband internet | Broadband internet |
| Steam target | 1080p Low · 60 FPS · upscaled | 1440p Medium · 70+ FPS native, or 4K Medium · 60+ FPS upscaled |

</div>

## How to read the two tiers

<div class="ref-index-grid">
<div class="ref-index-card"><strong>Minimum is not “1080p native”</strong><span>Steam explicitly ties the minimum tier to 1080p Low at 60 FPS with upscaling.</span><small>Target context</small></div>
<div class="ref-index-card"><strong>Recommended is a higher render target</strong><span>The recommended tier targets 1440p Medium above 70 FPS natively, or 4K Medium around 60 FPS with upscaling.</span><small>Target context</small></div>
<div class="ref-index-card"><strong>RAM and storage do not change by tier</strong><span>Both official tiers list 16 GB memory and 50 GB available storage.</span><small>Shared baseline</small></div>
</div>

## Before blaming the game or the PC

<div class="ref-split">
<div class="ref-panel">
<h3>Use a controlled test</h3>
<p>Match the Steam target as closely as possible: resolution, quality preset and whether upscaling is enabled. A result at a completely different target is not a direct comparison with the published requirement.</p>
<ul>
<li>Confirm the game is using the discrete GPU.</li>
<li>Update the graphics driver and reboot.</li>
<li>Disable nonessential overlays for one test run.</li>
<li>Check whether the issue is map-specific, server-specific or global.</li>
</ul>

## What this page does not claim

The official requirements do not provide a universal CPU/GPU benchmark table for every modern component. This Wiki therefore does not convert the published parts into unsupported equivalence tiers or guaranteed frame rates on unlisted hardware.
