## Triage in this order

<div class="ref-timeline">
<div><time>Step 1</time><section><strong>Check service status and maintenance</strong><span>If many players or servers are affected, local repair is unlikely to be the first useful step.</span></section></div>
<div><time>Step 2</time><section><strong>Try another server</strong><span>Compare one Official and one Community server when both are available.</span></section></div>
<div><time>Step 3</time><section><strong>Restart the game and Steam</strong><span>Reproduce the same failure before escalating.</span></section></div>
<div><time>Step 4</time><section><strong>Verify game files</strong><span>Use Steam's verification flow before reinstalling the whole game.</span></section></div>
<div><time>Step 5</time><section><strong>Test without nonessential overlays</strong><span>Remove injected variables for one clean reproduction attempt.</span></section></div>
<div><time>Step 6</time><section><strong>Record the failure</strong><span>Note the map, server type, error text, time and whether another server loads successfully.</span></section></div>
</div>

## Why the service check comes first

Launch-period official updates acknowledged server-join failures, unexpected kicks and long login queues. Those are not the same thing as a local map-loading crash, but they prove that a failed session can originate outside the local game files.

## Avoid unsafe or low-evidence fixes

This Wiki does **not** recommend deleting undocumented configuration folders, modifying anti-cheat internals or downloading third-party “repair” packages. Those steps are difficult to validate and can introduce a second problem before the first one is understood.
