WARDOGS players currently report a **Rebuy Last Loadout** action in the vendor workflow. That is different from maintaining several permanently named presets: rebuy is about repeating the previous purchase list quickly, then adjusting it for the next task.

> **Evidence boundary:** the current rebuy workflow is documented from recent player reporting rather than a complete official preset-system specification. Button placement and preset functionality can change during Early Access.

## Rebuy workflow

<div class="mechanic-flow">
<div class="mechanic-step"><strong>1. Open vendor</strong>Return to the equipment vendor after the failed life</div>
<div class="mechanic-step"><strong>2. Rebuy last</strong>Use the reported Rebuy Last Loadout action if it is present in the current build</div>
<div class="mechanic-step"><strong>3. Edit the cart</strong>Remove items that do not fit the next job and correct ammunition if needed</div>
<div class="mechanic-step"><strong>4. Check total</strong>Confirm the new spend before committing persistent cash</div>
</div>

## Rebuy is not the same as a saved preset

A rebuy action repeats the immediately previous purchase. A preset manager would maintain multiple named kits for different roles. Community discussion has treated these as separate concepts, so this Wiki does not claim a complete multi-preset manager exists unless the current client exposes it.

## What to review before pressing purchase

| Check | Question |
|---|---|
| Task | Am I doing the same job as the previous life? |
| Weapon | Does the same range and weapon class still make sense? |
| Ammo | Does the current weapon/ammo pair still match? |
| Utility | Did I actually use the specialist tools I bought last time? |
| Budget | Can I still afford another replacement after this purchase? |

## When not to rebuy unchanged

Do not blindly repeat a kit when the objective moved, the squad switched roles, you are now entering a vehicle, or the previous build failed because it was too expensive. Rebuy is a convenience tool, not a reason to stop evaluating the next life.
